# Team Charter

*How to use this template: This is your team's working agreement. Fill it out together during your first team meeting. The point isn't to produce a polished document. The point is to surface and resolve assumptions before they become friction. Be specific. "We'll communicate well" doesn't count. "We'll use Slack for day-to-day coordination and respond within 24 hours on weekdays" does. The charter can evolve, but you need a clear starting point that every team member has agreed to.*

## Communication norms

*How and when your team will communicate, and what response times you commit to. Most team friction comes from gaps between assumed norms and explicit ones. This is the section where you make those assumptions explicit.*

| Prompt | Your team's answer |
|---|---|
| **Primary platform for day-to-day coordination** *(Slack channel, group chat, shared email thread, etc.)* |  |
| **Response time expectations on weekdays** |  |
| **Response time expectations on evenings and weekends** |  |
| **Standing weekly meeting** *(when, where, how long)* |  |
| **How you'll handle missed meetings** *(who shares notes, when it becomes a concern)* |  |
| **Where shared files and updates live** *(the team's single source of truth)* |  |

---

## Contribution expectations

*How work gets divided, what counts as a finished piece of work, and what the team does when something is at risk of slipping.*

| Prompt | Your team's answer |
|---|---|
| **How you'll divide work** *(by role, by section, by week)* |  |
| **What "done" looks like for a draft** *before someone else reviews it* |  |
| **What happens if someone can't deliver on time** *(how soon they flag it, who picks it up)* |  |
| **How you'll flag problems early** *(before the deadline, not at it)* |  |

---

## Decision-making process

*How the team resolves disagreements when consensus isn't possible. Most teams skip this until they're already in a disagreement. By then it is harder to have the conversation calmly.*

| Prompt | Your team's answer |
|---|---|
| **How disagreements get resolved** *(majority vote, discussion to consensus, deliverable owner has final call)* |  |
| **Decisions that require full team consensus** |  |
| **Decisions any one team member can make on their own** |  |

---

## Conflict handling

*What you'll do when something isn't working between teammates. The hardest section to write, and the most important. Easy to skim past now; harder to build once a real conflict is already happening.*

| Prompt | Your team's answer |
|---|---|
| **How we'll raise a concern with each other** *(direct conversation, group discussion, written first)* |  |
| **Signs the team will watch for** *(missed deadlines, silence in meetings, shifts in tone)* |  |
| **When we'd bring something to the instructor or use the Riipen platform's escalation path** |  |
