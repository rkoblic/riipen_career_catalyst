# Week 8 — From Feedback to Forward Motion
## Content Development Plan

---

## Content Architecture

Week 8 is a **Pattern D (Dual anchor)** week with elements of Pattern C. Two distinct instructional challenges run in parallel: processing employer feedback from Check-In #1 and completing Peer Evaluation #1, the first graded individual deliverable. There is no employer touchpoint, which frees the largest production block in the course so far. The week reduces to five content pieces: a Week Overview, a Feedback Processing & Revision module, a standalone AI as a Production Partner page (a deliberate arc milestone — Week 8 is where the production partner role is first introduced as content), a Peer Evaluation #1 anchor prompt, and a What's Next. The flow is Overview → Feedback Processing → AI as Production Partner → Peer Evaluation anchor → What's Next.

### 2. Processing Feedback & Revision
**Type:** Standalone module
**Absorbs:** 8.02, 8.03

Two closely related modules covering the core feedback processing skills: sort feedback → build a revision plan → distinguish structural from targeted revisions. The AI content (8.05) is split to its own page to keep this page focused and scannable.

**Sub-elements:**

**Why iteration is the work, not a setback**
- Framing: revision in professional contexts is expected, not corrective (AI-generated video, ~1–2 min)

**Sorting employer feedback**
- The act-on / note / set-aside framework with criteria for each category (AI-generated text, ~400 words)
- Examples: what each category looks like for common Check-In #1 feedback types — scope push, methodology question, framing note (scenario cards, one per category, ~50 words each)

**Building a feedback response plan**
- How to convert debrief notes into a prioritized revision plan with owners and adjusted timelines (AI-generated text, ~300 words)
- Feedback Response Plan template: feedback item | category | revision required | owner | target date (Template)
- Note: seeds the Change Log habit without requiring a separate Change Log module

**Structural vs. targeted revisions**
- How to distinguish feedback that requires structural rethinking from feedback addressable through targeted edits; why this distinction matters for time allocation (AI-generated text, ~300 words)

**Time check:** 8.02 (15 min) + 8.03 (15 min) = 30 min allocated → ~900 words text (~4–5 min reading) + instructional video (~2 min) + scenario cards (~3 min) + thinking time ≈ 30 min. ✓

### 3. AI as a Production Partner
**Type:** Standalone module
**Absorbs:** 8.05

The Week 8 AI arc milestone — first introduction of AI in the production partner role. Given its significance in the arc and the length of the adjacent feedback processing page, treated as its own page rather than folded into page 2.

**Sub-elements:**

**The role shift**
- How AI's most useful role shifts from research tool to production partner in the Development phase (AI-generated text, ~200 words)

**What AI is well suited to in this phase**
- Structural review, gap identification after revision, self-editing before handoff — each with an example prompt (AI-generated text, ~300 words)

**What AI can't do in this phase**

**Time check:** 8.05 (10 min) → ~650 words text (~3 min reading) + curated link (~6–8 min) ≈ 10 min. ✓

### 4. Peer Evaluation #1
**Type:** Assignment prompt with embedded guidance
**Absorbs:** 8.04, 8.06

The primary graded anchor for the week. Module 8.04 (Writing Substantive Peer Evaluations) and activity 8.06 (reviewing the assignment and BARS rubric) both serve this deliverable directly and are consolidated here. The content teaches the evaluation frameworks, models strong vs. weak evidence, provides a calibration exercise, and then presents the assignment itself. The submission time (8.07, 105 min) is no-content.

**Sub-elements:**

**What peer evaluation is and why it matters**
- Professional framing: peer evaluation in workplace contexts; why evidence-based feedback is a skill, not an opinion (AI-generated text, ~200 words)

**The Continue/Start/Adjust framework**
- What each prompt asks for; how to write qualitative feedback that is specific, referenced to behavior, and useful to the recipient; 2-sentence minimum per prompt explained (AI-generated text, ~350 words)
- Weak vs. strong example pairs for each prompt type (Scenario cards, ~50 words each, 3 pairs)

**BARS dimensions and behavioral anchors**
- The four dimensions — Reliability, Contribution, Constructive Engagement, Accountability — with the behavioral anchors for each rating level (AI-generated text + reference card, ~400 words)
- What counts as behavioral evidence: specific, observable, time-bound examples vs. general impressions (AI-generated text, ~250 words)
- Weak vs. strong evidence examples for each dimension (Scenario cards, ~40 words each, 4 pairs)

**Calibration exercise: Maple & Main scenario**
- Students rate fictional teammate "Jordan" using the BARS dimensions based on a brief scenario description; guided discussion surfaces correct ratings and common miscalibration patterns (Interactive practice, ~10 min)

**The self-evaluation component**
- How to evaluate yourself on the same four BARS dimensions; why self/peer calibration gaps matter; what honest self-assessment looks like vs. strategic rating (AI-generated text, ~200 words)

**Assignment description**
- Full four-part structure: (A) Continue/Start/Adjust qualitative feedback, (B) BARS ratings with evidence, (C) self-evaluation, (D) team pulse questions (instructor-only); submission format; evidence requirements; flagging criteria (AI-generated text, ~350 words)

**AI guidance**
- Permitted: using AI to help articulate an observation more clearly or check specificity, with disclosure
- Off-limits: AI cannot generate the evaluation; the learning and the data both require genuine assessment
- Disclosure requirement for submission (AI-generated text, ~150 words)

**Time check:** 8.04 (20 min) + 8.06 (20 min) = 40 min module content + 8.07 (105 min) doing → ~1,900 words text (~9–10 min reading) + calibration interactive (~10 min) + scenario cards (~5 min) + thinking time ≈ 35–40 min for the instruction; 105 min for the work itself. ✓

### 5. What's Next
**Type:** Transitional prompt
**Absorbs:** nothing (forward-looking)

Brief transitional page orienting students toward Week 9. Check-In #2 is approaching — the second employer meeting. Peer evaluation results (anonymized qualitative feedback + aggregated BARS averages) will be shared back before the Week 9 Team Processing Session, where teams discuss the feedback and agree on behavioral changes. The production pressure continues: Week 9 carries one of the largest project work blocks in the course.
